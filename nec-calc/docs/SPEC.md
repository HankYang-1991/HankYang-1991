## 1. 目的與範圍

### 1.1 目的
提供 MEP 設計人員一套離線、免安裝套件的計算工具，依美國 NEC 選定 24.9 kV 三相至 120 V 單相系統中各迴路的保護設備、開關、導線、接地線、導線管／電纜架、匯流排槽，並計算盤負載、短路電流與諧波，輸出可追溯（每一步驟附條文）的計算書。

### 1.2 範圍
- **包含**：分路與幹線、馬達分路、變壓器一二次側、高壓電纜（≤ 35 kV）、匯流排槽、電纜架、盤負載計算（含 Excel / CSV 清單）、放射狀短路電流與 IC 值、變頻器諧波與濾波器、NEC 參考表。
- **不包含**：住宅單元負載計算（Article 220 Part III / IV）、網狀系統短路、單相接地故障、電弧閃絡、保護協調、諧振分析（請使用 ETAP 等專業軟體）。
- **規範版本**：NEC 2023 與 2026 可切換；≤ 1000 V 計算方法相同，> 1000 V 條文引用依 2026 改至 Article 235 / 245。
- **台灣用戶用電設備裝置規則**：列入藍圖，待取得官方條文表格後實作（第 13 章）。

### 1.3 使用者與情境
| 使用者 | 典型工作 |
|---|---|
| 電機設計工程師 | 逐一迴路選定導線／保護設備、檢核壓降、出計算書 |
| 專案經理 | 快速估算盤負載、幹線大小、變壓器與匯流排槽規格、與業主或廠商溝通 |
| 審查人員 | 依計算步驟與條文逐項核對 |

## 3. 設計原則（第一性原理）

本軟體的根本目的只有一件事：**從設計輸入，最快、最可信地得到符合 NEC 的選定結果，並能交付**。所有介面決策都由此推導：

| 編號 | 原則 | 推導出的設計 |
|---|---|---|
| P1 | 畫面上的結果必須永遠對應目前的輸入 | 輸入即自動重算；輸入無效時保留上一次有效結果，但以紅字明確標示「下方為上一次有效輸入的結果」；報告預設不勾選有輸入錯誤的頁面 |
| P2 | 答案先行 | 結果區第一行顯示最重要的選定結果與 ✓ 符合／⚠ 警告／✗ 不符合 |
| P3 | 錯誤要指出位置 | 非數字欄位立即以紅底標示；錯誤訊息指出欄位名稱 |
| P4 | 不打斷使用者 | 儲存、匯出成功只顯示在狀態列；只有需要決定或錯誤時才跳出對話框 |
| P5 | 不遺失工作 | 關閉時自動保存工作階段、下次開啟自動還原；每 2 分鐘自動保存；標題列 `*` 表示未儲存 |
| P6 | 可追溯 | 每一計算步驟附條文編號；TYPICAL 資料一律警告 |
| P7 | 少一步就少一步 | 快捷鍵（Ctrl+S/O/N/E、F5）、Delete 鍵刪除清單列、Excel 大量匯入、可複製結果 |
| P8 | 不依賴外部環境 | 只用 Python 標準函式庫；網頁版為單一 HTML + JS，可離線 |

## 4. 系統架構

### 4.1 模組

```
necalc/
├── tables.py        NEC 表格與製造商資料（純資料）
├── codes.py         各版本條文編號對照（2023 / 2026）
├── engine.py        導線／OCPD／EGC／導線管／壓降、馬達、變壓器、高壓電纜、匯流排槽
├── tray.py          電纜架（Article 392）
├── loads.py         盤負載計算（PF、DF、參差因數、相平衡、幹線）
├── shortcircuit.py  放射狀短路電流與 IC 值
├── harmonics.py     變頻器諧波、IEEE 519 檢核、濾波器選用
├── panel_io.py      Excel / CSV 盤負載清單匯入匯出
├── xlsx.py          標準函式庫 .xlsx 讀寫
├── i18n.py          英文／中文字串（唯一字串來源）
├── report.py        文字／HTML／CSV 輸出、結果首行答案
├── gui.py           Tkinter 桌面介面
└── __main__.py      python -m necalc 進入點
web/                 手機網頁版：necalc.js（引擎移植）、necalc_data.js（由 build_data.py 產生）、index.html
tools/build_desktop.py  電腦版安裝包
```

### 4.2 分層與相依規則
1. **資料層**（`tables.py`、`codes.py`、`i18n.py`）：只有資料，不含邏輯。
2. **計算層**（`engine.py`、`tray.py`、`loads.py`、`shortcircuit.py`、`harmonics.py`）：純函式，輸入資料類別、輸出 `Result`（`summary` 字典、`steps` 步驟、`warnings`、`children`）。步驟與警告存 i18n 鍵值與參數，不存已翻譯文字，因此可隨時切換語言重繪。
3. **輸出層**（`report.py`、`panel_io.py`、`xlsx.py`）：把 `Result` 轉成文字、HTML、CSV、Excel。
4. **介面層**（`gui.py`、`web/`）：只負責收集輸入、呼叫計算層、顯示結果；不得包含 NEC 計算邏輯。
5. 計算錯誤一律拋出 `CalcError(key, **params)`，由介面翻譯顯示。

### 4.3 技術選型
| 項目 | 選擇 | 理由 |
|---|---|---|
| 語言 | Python 3.9+（實測 3.11–3.13） | 工程師熟悉、跨平台 |
| 桌面介面 | Tkinter / ttk（clam 佈景） | Python 內建，免安裝 |
| Excel | 自寫 `xlsx.py`（zipfile + ElementTree） | 不需 openpyxl |
| 網頁版 | 原生 JavaScript，資料由 Python 產生 | 可放在 claude.ai，手機可用、可離線 |
| 數值一致性 | `math.fsum`、Python 式四捨五入（JS 端 `toFixedPy`） | 確保 Python 與 JS 結果逐字相同 |

## 5. 功能需求

每一功能的輸出皆包含：摘要、編號步驟（含條文）、警告；並可匯出 HTML 報告。

### FR-01 分路／幹線（分路 / 幹線頁）
- **輸入**：迴路類型（分路／幹線）、負載種類、負載值與單位（VA、kVA、W、kW、A）、功率因數、連續負載比例、指定保護設備（空白＝自動）、最大馬達 VA（幹線）；配線方式（電壓、系統 1Ø2W／1Ø3W／3Ø3W／3Ø4W、電纜或匯流排槽、銅／鋁、THHN／XHHW、端子溫度 60／75／90 °C、導線管 EMT／IMC／RMC／PVC40／PVC80、最小線徑）；安裝條件（單程長度、壓降限制、周溫、同管其他 CCC、並聯組數、自動並聯最大線徑、中性線計為 CCC）。
- **處理**：設計電流 = 125 % 連續 + 100 % 非連續（+ 25 % 最大馬達）；選標準 OCPD（240.6(A)）；選最小線徑同時滿足：端子溫度欄安培容量 ≥ 設計電流（110.14(C)）、90 °C 安培容量 × 周溫修正 × CCC 調整 ≥ 負載電流、受 OCPD 保護（240.4(B)、(D)）；超過最大線徑自動並聯（310.10(G)）；壓降超限自動加大並等比例加大 EGC（250.122(B)）；導線管填充（Chapter 9 Tables 1／4／5）。
- **輸出**：負載電流、設計電流、OCPD、隔離開關、導線組成、安培容量、壓降 %。

### FR-02 馬達（馬達頁）
- **輸入**：HP（1/6–500）、保護設備（ITCB、延時熔絲、非延時熔絲、瞬時跳脫 MCP）、銘牌 FLA、FLC 自訂（非表列電壓）、SF 1.15、Design B 高效率；配線方式（無匯流排槽）。
- **處理**：FLC 查表 430.248／430.250；導線 125 % FLC（430.22）；分路短路接地保護上限 Table 430.52(C)(1)；過載 125 %／115 %（430.32(A)(1)）；HP 額定隔離開關（430.110(A)）。
- **輸出**：FLC、設計電流、保護設備、過載設定、隔離開關、導線、壓降。

### FR-03 變壓器（變壓器頁）
- **輸入**：kVA、一次／二次電壓、相數、阻抗 Z %、場所（任何／有監督）、一次／二次保護型式、≤ 1000 V 保護方式、一次側長度、一次側配線型式（電纜／匯流排槽）、一次側可用故障電流；二次側沿用配線群組（預設匯流排槽）。
- **處理**：一二次額定電流；二次側無限匯流排短路電流；> 1000 V 依 Table 450.3(A)、≤ 1000 V 依 Table 450.3(B) 決定保護上限與選定值；一次側 > 1000 V 時以 FR-04 選高壓電纜，否則選低壓導線或匯流排槽；二次側導線依 240.21(C)。
- **輸出**：一次／二次電流、短路電流、一次保護（選定／上限）、二次保護，以及一次側、二次側子結果。

### FR-04 高壓電纜（高壓電纜 24.9 kV 頁）
- **輸入**：kV、負載電流、銅／鋁、絕緣等級（25 kV 100 %／133 %、35 kV 100 %）、設計係數、保護型式（熔絲／電驛）與額定、故障電流、清除時間、導體運轉／短路溫度、導線管、電纜外徑、是否含 EGC。
- **處理**：依電壓最小線徑（Table 315.10(A)）；安培容量（315.60，TYPICAL 值並警告）；短路耐受（ICEA P-32-382）；導線保護（熔絲 ≤ 3 倍、電驛 ≤ 6 倍安培容量；2023 引用 240.101(A)，2026 引用 Article 245）；EGC（250.190(C)(3)）；導線管填充與卡線比。
- **輸出**：電纜規格、安培容量、短路所需 cmil、卡線比。

### FR-05 匯流排槽（任何幹線可選）
- **資料**：施耐德 I-Line 型錄 5600CT9101（2018/03）：Table 5 R／X（mΩ／100 ft，80 °C）、Table 1 SCCR（饋線型／插接型 × 標準／高耐受）、Table 6 鋁接地匯流排電阻。鋁 225–4000 A、銅 225–5000 A；饋線型 800 A 以上；超過最大額定以 2 路並聯（如 6000 A = 2 × 3000 A）。
- **處理**：OCPD 依 368.17(A)；周溫 40 °C 以上降額 √((95 − Ta)/55)；集中／分布負載壓降；依可用故障電流自動選標準或高耐受；可輸入其他廠牌 R／X／SCCR；產生 I-Line 型號字首（如 `CPH2540G`）。

### FR-06 電纜架（電纜架頁）
- **輸入**：型式（梯型、通風槽、實底）、深度 3–6 in、寬度（0 = 自動）、敷設方式（隨意／間隔）、周溫、實心蓋板；電纜清單（低壓多芯、低壓單芯、控制、中壓單芯、中壓多芯；線徑、芯數、數量、外徑、材質、絕緣等級）。
- **處理**：392.22(A)／(B)(1)／(C) 填充、中低壓同架需隔板（392.20(B)）、安培容量（392.80）、選 NEMA VE 1 標準寬度 6／9／12／18／24／30／36 in（非標準寬度內插並提示）。
- **輸出**：電纜架寬度、需求寬度、使用率；**容量對照表**（各寬度最多可放電纜數）。

### FR-07 盤負載計算（盤負載計算頁）
- **輸入**：多個盤；每盤：盤名、系統（208Y/120、480Y/277、480D、240/120 1PH、120 1PH）、參差因數（≥ 1）、目標功因、幹線長度（空白 = 配線頁設定）；負載：迴路、名稱、類別（照明、插座、馬達、電熱、空調、設備、其他）、數量、每台額定、單位（VA、kVA、W、kW、HP、A）、PF、電壓、相數、連續、需量因數（空白 = 自動）、接相（自動、A、B、C、AB、BC、CA、ABC）。
- **處理**：各負載 kW／kvar／kVA；自動需量因數：插座 10 kVA 以內 100 %、其餘 50 %（220.47）、電熱與空調取大者（220.60）；同時需量 = Σ 需量 ÷ 參差因數；幹線設計 = 同時需量 + 25 % 連續 + 25 % 最大馬達（215.2、430.24）；自動相平衡、不平衡率；改善至目標功因所需電容 kvar；幹線選定（FR-01 / FR-05）。
- **輸出**：單盤明細與摘要，或「計算全部盤」一盤一列彙總表（連接、需量、同時、設計 kVA，設計電流，保護器，壓降，幹線）。

### FR-08 Excel / CSV 盤負載清單（盤負載計算頁工具列）
- **範本**：工作表「說明」、「盤清單」、「負載清單」，附範例列與下拉選單。
- **匯入**：`.xlsx`、`.xlsm`、`.csv`（UTF-8／Big5；`,` `;` Tab 分隔）。可選全部取代或新增／更新同名盤；匯入後自動計算全部盤。容錯規則見第 7.3 節；所有推定與略過的資料列在「匯入注意事項」並標示工作表與列號。
- **匯出**：彙總（SUM 公式合計）、盤清單、負載清單（可修改後再匯入）、每盤一張計算表（含幹線選定）。
- **限制**：不支援舊版 `.xls`。

### FR-09 短路／IC 值（短路 / IC 值頁）
- **輸入**：電源電壓、可用故障電流（0 = 無限大）、X/R、變壓器阻抗 −10 % 公差；放射路徑元件清單：變壓器（kVA、Z %、X/R、二次電壓）、電纜（長度、線徑、組數、材質、鋼管／PVC）、匯流排槽（額定、長度）；各匯流排保護設備型式（MCCB、ICCB、LVPCB、熔絲）、選用 IC、馬達負載電流。
- **處理**：歐姆法；電纜用 Chapter 9 Table 9、匯流排槽用 I-Line R／X，R 換算至 25 °C；馬達貢獻 4 × FLC；依 IEEE 1015 測試 X/R（MCCB／ICCB／熔絲用峰值比，LVPCB 用有效值比）修正；最小 IC 由標準等級 10–200 kA 選定；檢核選用值；110.24 標示提醒。
- **輸出**：各匯流排對稱短路電流、X/R、修正係數、最小 IC、選用檢核；最大故障電流。

### FR-10 諧波／濾波器（諧波 / 濾波器頁）
- **輸入**：PCC 電壓、PCC 短路電流、最大需量電流 I_L（0 = 依連接負載）、其他線性負載；變頻器清單（名稱、數量、HP、前端型式 6 脈波／3 % 或 5 % 交流電抗器／直流電抗器／12 脈波／18 脈波／AFE／被動濾波器、負載率、輸入電流、原廠 THDi）。
- **處理**：典型頻譜（或原廠 THDi）算術加總；IEEE 519-2022 Table 2 個別諧波與 TDD 限制（依 Isc/I_L）、Table 1 電壓 THD；K 因數（IEEE C57.110）；改善方案比較（5 % 電抗器、被動濾波器、18 脈波）；主動濾波器容量以限制值 90 % 為目標，選 60／120／200／300 A 框架（典型值）。
- **輸出**：TDD 與限制、電壓 THD、Isc/I_L、K 因數、主動濾波器容量。

### FR-11 參考資料（參考資料頁）
內建表格：310.16、310.17、310.15(B)(1)(1)、310.15(C)(1)、250.122、Chapter 9 Table 4／5／9、430.248、430.250、430.52、450.3(A)、392.22、高壓典型值、I-Line 匯流排槽。

### FR-12 報告與匯出
- HTML 計算書：選定頁面的輸入、摘要、步驟、條文、警告；使用目前語言與 NEC 版本。

- 結果區「複製」：首行答案 + 全部結果文字複製到剪貼簿。

### FR-13 專案檔與工作階段
- 新專案（Ctrl+N）、開啟（Ctrl+O）、儲存（Ctrl+S，已有檔名時直接覆寫）、另存新檔（Ctrl+Shift+S）。

## 8. 主要計算規則摘要
| 項目 | 規則 |
|---|---|
| 壓降 | 有效阻抗 Z = R·cosθ + X·sinθ（Chapter 9 Table 9，75 °C）；單相 2·I·Z·L，三相 √3·I·Z·L |
| 線徑選定 | 見 FR-01 處理步驟；Motor 依 240.4(G) 例外 |
| 並聯 | 超過最大線徑自動增加組數，每組 ≥ 1/0、各自管路、全尺寸 EGC（250.122(F)） |
| 匯流排槽降額 | √((95 − Ta)/55)，Ta ≥ 40 °C |
| 短路 | 歐姆法，變壓器阻抗可 −10 %；R 換算至 25 °C；馬達 4 × FLC |
| 需量 | 插座 10 kVA + 50 %；電熱／空調取大者；同時需量 ÷ 參差因數 |
| 諧波 | 各變頻器同次諧波算術加總；TDD = √Σ I_h² / I_L × 100 %；V_h ≈ 100·h·I_h / I_sc（%），VTHD = √Σ V_h²；K = Σ I_h²·h² / Σ I_h² |

## 14. 規格書維護規則（每次更新必須同步）
1. 任何影響功能、介面、資料格式、計算規則或建置方式的修改，都必須在同一個 commit 內更新本文件。
2. 更新內容至少包括：
   - `necalc/__init__.py` 的 `__version__` 與本文件首頁「對應程式版本」一致；
   - 「修訂紀錄」新增一列（版本、日期、內容）；
   - 受影響的章節（功能需求、介面規則、資料格式、測試、藍圖）。
3. `nec-calc/CLAUDE.md` 記載本規則，供協作的 AI 開發工具每次自動遵循。
4. `tests/test_spec.py` 自動檢查：版本一致、修訂紀錄含目前版本、每個 `necalc/*.py` 模組、每個頁面名稱、每個測試檔都已記載。檢查不通過即視為測試失敗。
5. 規格書以繁體中文撰寫，專有名詞附英文；檔案位置固定為 `nec-calc/docs/SPEC.md`，並隨電腦版安裝包發行（安裝包根目錄 `軟體開發規格書.md` 與 `source/docs/SPEC.md`）。
